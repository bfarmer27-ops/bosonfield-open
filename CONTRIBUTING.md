# Contributing to BosonField

BosonField accepts small, testable changes.

## Good first contributions

- Run one published workflow on hardware not yet listed.
- Repair one unclear lesson step.
- Add one exact error message and a tested repair.
- Check one model license against its official source.
- Add captions or translate a lesson after the English steps are final.

## What every workflow report includes

1. Operating system and version.
2. GPU name and video-memory amount.
3. System-memory amount.
4. Exact model and software versions.
5. Exact input size, output size, frame count, and seed.
6. Run time and peak memory.
7. Output file or hash when redistribution is not allowed.
8. The model license URL checked that day.

## Pull request checks

- No secrets, personal data, paid model files, copied prompts, or unlicensed media.
- The change has a clear test or repeatable manual check.
- Links open and point to the exact source claimed.
- New words are written for a first-time user.
- Model terms are described as their owner describes them. Do not replace “community license” or “open weights” with “open source.”

## Public conduct

By taking part, you agree to follow [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md). Do not send security reports to a public issue; use [SECURITY.md](SECURITY.md).
