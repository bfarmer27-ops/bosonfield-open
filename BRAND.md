# Brand guide

## Name

- Public display: **BosonField**
- Short display where space is tight: **BosonField**
- Handle target: **@bosonfieldopen**
- Say the words as written: **BosonField**.

## One-line promise

**Open-source AI video, made usable.**

## Mission

BosonField gives beginners free lessons, tested workflow files, honest hardware results, and open software for making AI video.

## Voice

- Use short, exact steps.
- Show proof before praise.
- Name costs, hardware, limits, and model licenses.
- Never insult a paid tool or its users.
- Never promise “free” when cloud compute, electricity, storage, or a model license adds a real cost.
